# 哀鸿

一部以明清易代为背景、经过艺术加工的古风历史幻想视觉小说。

## 当前内容

- 四章完整主线与四个结局
- 统一的晚明水墨电影感章节背景
- 标题音乐、环境音效、雪与灰烬演出
- Windows、Linux、macOS 的 Ren'Py 发行配置

## 开发检查

项目需要 Ren'Py 8.5。设置 `RENPY_SDK` 为 Ren'Py SDK 目录后，在 Git Bash 中执行：

```bash
./scripts/lint.sh
./scripts/run.sh
```

检查与运行记录写入 `logs/`。
